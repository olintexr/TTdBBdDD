# Ejercicio: Módulo de control de préstamos y sucursales

## Objetivo

Desarrollar un script SQL en SQL Server que integre los temas vistos en clase: vistas, CTE, procedimientos almacenados, joins y triggers de validación.

## Instrucciones generales

Crear un archivo SQL que implemente un módulo funcional sobre las tablas del esquema bancario.

El ejercicio debe incluir:

- la creación de tablas,
- la inserción de datos,
- una vista para mostrar préstamos extendidos,
- un CTE para listar préstamos altos,
- procedimientos almacenados para insertar y actualizar préstamos,
- un trigger para validar montos negativos,
- y un bloque final de pruebas.

## Especificaciones del ejercicio

### 1. Crear las tablas base

Crear las tablas necesarias para soportar el ejercicio. Se recomienda usar al menos estas tablas:

- `Sucursal`
- `Cuenta`
- `Prestamo`

### 2. Insertar datos

Insertar al menos 8 registros en total entre las tablas del ejercicio.

Los inserts deben estar incluidos dentro del mismo script.

### 3. Crear una vista de préstamos extendidos

La vista debe mostrar:

- número de préstamo,
- monto original,
- monto con un 10 % adicional.

### 4. Crear un CTE para listar préstamos altos

El CTE debe:

- filtrar préstamos con monto mayor a 50 000,
- mostrar el nombre de la sucursal mediante JOIN.

### 5. Crear un stored procedure para insertar préstamos

El procedimiento debe:

- recibir número de préstamo, sucursal y monto,
- verificar si el número de préstamo ya existe,
- insertar el registro si no existe,
- y manejar errores con TRY/CATCH.

### 6. Crear un stored procedure para actualizar montos

El procedimiento debe:

- recibir número de préstamo y nuevo monto,
- validar que el préstamo exista,
- validar que el nuevo monto no sea negativo,
- y actualizar el préstamo.

### 7. Crear un trigger para controlar montos inválidos

El trigger debe:

- ejecutarse después de `INSERT` y de `UPDATE`,
- revisar la tabla `inserted`,
- e impedir montos negativos.

### 8. Incluir pruebas mínimas

El script debe terminar con pruebas sencillas para verificar que:

- se puedan insertar varios préstamos,
- se pueda actualizar un monto,
- se consulte la vista,
- y se ejecute el CTE.

## Recomendaciones

- Organizar el script en secciones comentadas.
- Usar nombres claros para objetos y columnas.
- Mantener el código limpio y legible.
- Evitar usar funciones externas o herramientas adicionales.

## Formato esperado

El ejercicio debe entregarse como un único script SQL, con todo el código ordenado y comentado.

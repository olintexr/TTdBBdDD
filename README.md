# TTdBBdDD — Tópicos de Bases de Datos

Este repositorio contiene el material oficial de la asignatura Tópicos de Bases de Datos, organizado como un mini-libro digital en formato Markdown.

Su objetivo es ofrecer un espacio claro, didáctico y ordenado para estudiar, practicar y revisar los temas del curso, con ejemplos reproducibles y materiales listos para trabajar en SQL Server.

---

## Estructura del repositorio

- [01-resumenes](01-resumenes): contiene los temas del curso organizados por unidad.
- [02-ejercicios](02-ejercicios): incluye ejercicios prácticos y guías de trabajo.
- [03-material-de-apoyo](03-material-de-apoyo): reúne archivos complementarios como hojas de apoyo y recursos visuales.

## Cómo usar este repositorio

1. Leer primero el resumen correspondiente.
2. Revisar los ejemplos SQL incluidos en el mismo archivo.
3. Resolver el ejercicio práctico asociado.
4. Usar los materiales de apoyo para profundizar en los temas.

## Nota final

Los materiales están pensados para seguir un orden pedagógico: primero conceptos, luego ejemplos y finalmente ejercicios. Esta estructura facilita el estudio y la práctica en clase.

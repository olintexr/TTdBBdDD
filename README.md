
# TTdBBdDD — Tópicos de Bases de Datos - Por Olinto Rodríguez-Atencio

Este repositorio contiene el material oficial de la asignatura **Tópicos de Bases de Datos**, organizado como un **mini‑libro digital** en formato Markdown.  
Su objetivo es ofrecer un espacio claro, didáctico y estructurado donde los estudiantes puedan estudiar, practicar y descargar el contenido, manteniendo la integridad del material mediante acceso de solo lectura.

El repositorio sigue la misma filosofía utilizada en FFdBBdDD: claridad conceptual, narrativa didáctica, ejemplos reproducibles y reglas estrictas para la entrega de asignaciones.

---

## Estructura del repositorio

El repositorio está organizado en carpetas numeradas para mantener orden y coherencia:

- **01-resumenes/**  
  Contiene los capítulos del curso en formato Markdown. Cada capítulo funciona como una unidad de estudio independiente.

- **02-ejercicios/**  
  Incluye ejercicios prácticos, guías de trabajo y actividades complementarias.

- **03-material-de-apoyo/**  
  Contiene recursos adicionales como diagramas, referencias, notas técnicas y ejemplos extendidos.

---

## Filosofía del curso

1. Explicar cada tema desde su **idea central**.  
2. Presentar **conceptos fundamentales** con claridad y sin ambigüedades.  
3. Ubicar cada tema dentro de un **sistema mayor** (ecosistema de bases de datos).  
4. Describir **niveles, dimensiones o capas** del concepto.  
5. Introducir **herramientas, lenguajes o tecnologías** asociadas.  
6. Exponer **principios clave** que guían el diseño y la práctica.  
7. Mostrar **ejemplos ejecutables** y reproducibles.  
8. Conectar cada capítulo con la **bibliografía base**.  
9. Incluir un **glosario** para reforzar vocabulario técnico.  
10. Añadir un **mini‑quiz** para autoevaluación.  
11. Proponer **ejercicios prácticos**.  
12. Cerrar con una **asignación formal** con reglas estrictas de entrega.

---

## Política de acceso y protección del repositorio

Para garantizar la integridad del material:

- La rama **main** es pública para lectura.  
- Solo el profesor puede modificar el contenido.  
- Se aplican reglas de protección:  
  - Restrict updates  
  - Restrict deletions  
- El único bypass permitido es para **Repository admin (Role)**.

Los estudiantes pueden clonar o descargar el repositorio, pero no pueden modificarlo.

## Bibliografía recomendada

**Silberschatz, Abraham; Korth, Henry; Sudarshan, S. — *Database System Concepts*.**  
Referencia fundamental para comprender modelos, SQL, transacciones y arquitectura.

**Elmasri, Ramez; Navathe, Shamkant — *Fundamentals of Database Systems*.**  
Profundiza en diseño conceptual, normalización y modelos.

**Itzik Ben‑Gan — *T‑SQL Fundamentals*.**  
Lectura prioritaria para aprender T‑SQL de forma clara y práctica.

**Microsoft Learn – SQL Server Documentation**  
https://learn.microsoft.com/sql  
Referencia oficial para sintaxis, ejemplos y comportamiento del motor.

**Garcia‑Molina, Ullman, Widom — *Database Systems: The Complete Book*.**  
Teoría avanzada, transacciones y concurrencia.

**Itzik Ben‑Gan — *Inside Microsoft SQL Server: T‑SQL Programming*.**  
Optimización y técnicas profesionales de T‑SQL.

**Joe Celko — *SQL for Smarties*.**  
Problemas complejos y soluciones avanzadas en SQL.

**Markus Winand — *SQL Performance Explained*.**  
Índices, planes de ejecución y optimización.

**PostgreSQL Documentation**  
https://www.postgresql.org/docs/

**MySQL Reference Manual**  
https://dev.mysql.com/doc/
